# Cinemana for Nuvio

إضافة سينمانا محلية لهواتف أندرويد وشاشات أندرويد: أفلام، حلقات، جميع الجودات المتاحة ومنها 2160p/4K وترجمات عربية وإنكليزية.

## التثبيت

داخل Nuvio افتح Plugins ثم Add Repository والصق الرابط:

https://raw.githubusercontent.com/husseinadnan1/nuvio-cinemana/main/manifest.json

فعّل Cinemana، ثم افتح الفيلم أو الحلقة من مكتبة Nuvio واختر مصدر Cinemana. الجهاز نفسه يجب أن يكون على شبكة يعمل عليها موقع سينمانا. اللابتوب ليس مطلوباً بعد التثبيت. إذا لم يظهر قسم Plugins، تحتاج نسخة Nuvio التي تدعم الإضافات المحلية.

## التحقق والحدود

تم اختبار البحث عن Breaking Bad S02E05 وInception من اتصال يدعم سينمانا، واسترجاع الجودات والترجمات، وقراءة 1024 بايت من الفيديو بعد تحويل CDN باستجابة 206. رجعت الحلقة بجودة 2160p و1080p و720p و480p و360p و240p؛ الفيلم حتى 1080p. النسخة المنشورة تطابق الكود المختبر.

لم يتم بعد اختبار فك الترميز داخل جهاز أندرويد الفعلي. دعم 4K يعتمد أيضاً على المشغل والجهاز. لا تعرض الإضافة HDR أو HEVC دون بيانات تؤكد ذلك.

## طريقة العمل

تستخدم مفتاح TMDB الذي يتيحه Nuvio، مع بديل يعتمد على صفحة TMDB العامة. تدعم معرف IMDb عبر Cinemeta أيضاً. تبحث في Cinemana بالعنوان، وتطابق السنة والنوع ومعرف IMDb إن توفر. ترفض المطابقات الملتبسة والحلقة غير الموجودة. البحث محدود بالصفحة الأولى لكل واحد من عنوانين، وقد يفوّت أعمالاً ذات أسماء مختلفة.

تُجلب الروابط الموقعة حديثاً لكل بحث عن المصادر. لا يحتوي المستودع cookies أو كلمات مرور أو رموز جلسة أو روابط فيديو موقعة. لا يلزم خادم بث خارجي؛ الكود يعمل على جهاز Nuvio.
